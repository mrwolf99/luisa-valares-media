# Vídeos de luisavalares.com

Este repositorio solo guarda los vídeos propios de la web de Luisa Valares.
GitHub Pages los sirve en **https://media.luisavalares.com/<archivo>.mp4**.

Están aquí y no en la web porque Cloudflare, donde vive la web, no deja
saltar dentro de un vídeo (no responde a las peticiones por rango) y el
Safari del iPhone no reproduce vídeos sin eso. GitHub Pages sí.

## Añadir un vídeo

1. Conviértelo a H.264 (MP4), de 1280 px de ancho como máximo. Cada archivo
   tiene que pesar menos de 100 MB (límite de GitHub); mejor menos de 25 MB.
2. Súbelo aquí con un nombre sin espacios ni tildes: `nombre-del-corto.mp4`.
3. En la web, en el campo del vídeo, pon
   `https://media.luisavalares.com/nombre-del-corto.mp4`.

No cambies el nombre de un vídeo que ya está en la web: el navegador puede
tener guardado el viejo durante un tiempo.
